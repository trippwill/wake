# Research

Durable learnings from external documentation and experiments, retained to avoid
repeating useful investigations. Each memo addresses a focused question and leads
with its conclusion.

These notes are optional supporting evidence. Product decisions, architecture,
release coverage and task status remain with their owning documents.
See the [Wake docs skill](../../.agents/skills/wake-docs/SKILL.md#folder-purposes-and-rules)
for research content and maintenance rules.
