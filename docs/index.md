# Wake user docs

Wake keeps a financial history on a Linux machine you control. It synchronizes
authorized sources, retains their original reports, and lets you inspect
accepted activity alongside the evidence behind it.

These guides cover [v0.1.0-rc.2](https://github.com/trippwill/wake/releases/tag/v0.1.0-rc.2),
a prerelease.

- [Get started](get-started.md) to install Wake and sign in.
- Connect [IBKR Flex](sources/ibkr-flex.md) or [SnapTrade Personal](sources/snaptrade.md)
  to synchronize a financial account.
- [Review your financial history](history.md) to check freshness, trace a record
  to its source, or correct accepted data.
- Operate the [Podman appliance](deployment/wake-appliance.md) or the
  [native command](deployment/native.md) to set up private LAN access, back up,
  update, or recover Wake.
- [Connect an app](connect-an-app.md) to read data from the CLI, Codex, or another
  client.

For project updates and questions, visit
[Wake on GitHub](https://github.com/trippwill/wake).
